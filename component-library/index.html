Paw Rescue UI

A reusable component library built for the Paw Rescue brand. All components follow a consistent design language — warm amber/charcoal palette, accessible by default, and customizable via CSS variables.

Usage: Copy any component's HTML + its CSS class from style.css. All components use CSS custom properties so they can be themed by changing the root variables.

Design Tokens

All components use these CSS custom properties defined in :root.

--bg #1A1714
--card #2B2520
--amber #E8A24B
--sage #7C9070
--cream #F7F1E8
--error #E0664E

Buttons

Three variants — Primary, Ghost, and Danger. All support disabled state and focus styles for keyboard navigation.

HTML
<button class="pr-btn pr-btn--primary">Primary</button>
<button class="pr-btn pr-btn--ghost">Ghost</button>
<button class="pr-btn pr-btn--danger">Danger</button>
<button class="pr-btn pr-btn--primary" disabled>Disabled</button>

Sizes

HTML
<button class="pr-btn pr-btn--primary pr-btn--sm">Small</button>
<button class="pr-btn pr-btn--primary">Medium</button>
<button class="pr-btn pr-btn--primary pr-btn--lg">Large</button>

Inputs

Form inputs with three states — default, error, and success. Includes helper text and label patterns.

Enter the city where you spotted a stray.

Please enter a valid email address.

Looks good!

HTML
<div class="pr-field">
  <label class="pr-field__label" for="city">City name</label>
  <input type="text" id="city" class="pr-field__input" placeholder="e.g. Delhi">
  <p class="pr-field__hint">Helper text here.</p>
</div>

<!-- Error state -->
<div class="pr-field pr-field--error"> ... </div>

<!-- Success state -->
<div class="pr-field pr-field--success"> ... </div>

Alerts

Four semantic alert variants for user feedback — info, success, warning, and error.

Info: Rescue team has been notified and is on the way.
Success: Your volunteer signup was submitted!
Warning: High heat today — strays need extra water.
Error: Could not fetch weather data. Try again.
HTML
<div class="pr-alert pr-alert--info" role="status">Info message</div>
<div class="pr-alert pr-alert--success" role="status">Success message</div>
<div class="pr-alert pr-alert--warning" role="alert">Warning message</div>
<div class="pr-alert pr-alert--error" role="alert">Error message</div>
